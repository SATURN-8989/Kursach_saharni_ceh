# Описание практических шагов выполнения работы

## 1. Автоматизация маркетинга (Instagram)
* **Кадр:** `screens/instagram/05_instagram_manychat_bot.png`
* **Описание:** Настройка и публикация логической схемы чат-бота в ManyChat. Бот успешно перехватывает кодовое слово "ТОРТ" в комментариях к публикации Instagram и автоматически отправляет клиенту в Директ приветственное сообщение с кнопкой перехода на сайт через укороченную ссылку кликера.

## 2. Сбор и консолидация транзакций в СУБД
* **Кадр:** `screens/datastudio/06_datalens_connection_success.png`
* **Описание:** Фиксация успешного прохождения тестовых лидов через API-обработчик в облачную базу данных Google Sheets (лист `leads`). Массив данных содержит метки сквозной аналитики и валидные телефонные номера.

## 3. Профилирование и скрытие данных
* **Кадр:** `screens/datastudio/08_datalens_hidden_fields.png`
* **Описание:** Настройка безопасности данных в интерфейсе датасета Яндекс DataLens. Согласно регламенту лекции (Слайд 63), для полей персональных данных (имя, телефон, почта) принудительно активирован статус "Скрыто".

## 4. Визуализация и интерактивный дашборд
* **Кадр:** `screens/datastudio/10_datalens_dashboard_final.png`
* **Описание:** Итоговая панель сквозной аналитики проекта "Сахарный цех" в Яндекс DataLens. На холст выведена круговая диаграмма популярности типов тортов и рассчитана конверсия маркетинговой воронки.
